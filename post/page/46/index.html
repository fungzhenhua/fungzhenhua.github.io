发表于： 2023-06-23

将shell命令赋值给变量有两种不同的方法，这对于shell脚本编程特别有用，这两种形式为：

1
2
3
4
5

变量名=$(命令)
变量名=$(命令 [命令选项...] 参数1 参数2)
或者
变量名=`命令`
变量名=`命令 [命令选项...] 参数1 参数2`

{% note warning %} 第二种方法中使用的是键盘左上角Esc键下面的反引号,多数键盘上和符号～在同一个键上，并不是键盘右侧的单引号，这一点特别注意。 {% endnote %}
