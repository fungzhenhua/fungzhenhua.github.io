自定义Hugo Next主题

发表于： 2026-11-19

最近从 Hexo 切换到 Hugo，通过对 Hugo Next 主题的深入研究，我对其进行了若干修改，以更好地满足个人需求。本文将记录这些改动。

主题颜色的改动

修改基本配色 

1
2
3
4
5

# themes/hugo-theme-next/assets/css/_variables/base.scss
// Color system
// --------------------------------------------------
// $black-deep   : #222;
$black-deep   : #9400D3; // 深紫色

修改配置文件

根目录hugo.yaml第775行，修改为

1
2
3
4

themeColor:
# Violet color
    light: "#9400D3"
    dark: "#9400D3"

标题的隐藏

复制 Hugo-Next 的 post.html文件到根目录中的 layouts：

1

cp themes/hugo-theme-next/layouts/_partials/post.html ./layouts/partials/post.html

将18,19,20行追加上hide_title的判断，如果不在Front Matter中设置hide_title = true, 则显示标题，否则隐藏标题. 于是修改为

1
2
3
4
5

{{ if not .ctx.Params.hide_title }}
<header class="post-header">
{{ partial "post/header.html" (dict "ctx" .ctx "IsHome" .IsHome) }}
</header>
{{ end }}

隐藏文章底部的虚线

原始模板在分享和赞赏之间有一条修饰的虚线，但是我感觉这不够简洁正式，于是决定去除这条线。于是修改文件static/css/custom_style.css ， 在底部追加虚线隐藏判断命令：

1
2
3
4

/* 隐藏文章底部的虚线分割线 */
.post-footer hr {
    display: none !important;
}

同时在hugo.yaml中第328行，启用自定义文件，即

1
2
3
4
5
6

# 用户自定义文件配置
# Define custom file paths.
customFilePath:
sidebar: # custom_sidebar.html
footer:  # custom_footer.html
style:   /css/custom_style.css

  display: none !important;
}

隐藏表头和加黑表头控制

在导航、收藏、软件等部分，以Markdown表格组织博客，但是它们不需要表头，因此需要一个空表头，但是不渲染的效果。于是同时增加了两个功能：

  • 增加表头隐藏功能，在表格的最底部加上{.no-header}.
  • 增加表头不加黑功能，在表格的最底部加上{.plain-header}.
