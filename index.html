GNOME登出按键消失与恢复

发表于 2026-11-02

适用场景：GNOME 桌面右上角菜单中找不到“登出”选项，希望恢复显示。

现象说明

GNOME 的登出按键并不是在某一个版本被“永久取消”，而是一个早在 2012 年就已确定的设计，直到 GNOME 50 版本才因相关错误被修复而真正生效。因此，对于许多用户来说，它看起来像是在 GNOME 50 中被“移除”了。

如何恢复登出按键

恢复登出按键非常简单，只需在终端中执行一条 gsettings 命令即可。这个设置会覆盖默认行为，让登出选项始终显示在系统菜单中。

执行后，登出按键应该会立即重新出现在右上角的快捷设置菜单中。

在哪个版本“取消”的？

这需要分两层来看：

  • 设计理念的起源：GNOME 3.6（2012 年） 隐藏单用户系统登出按钮的设计意图，最初是在 2012 年左右被 GNOME 设计团队采纳的，大致与 GNOME 3.6 版本同期。当时的目标是：当系统只有一个用户账户时，为了简化界面而隐藏登出选项。

  • 设计真正生效：GNOME 50（2026 年） 尽管设计在 2012 年就已确定，但由于 GNOME 其他组件的多个错误，这个设计在长达十几年的时间里并没有实际生效。绝大多数用户看到的仍然是登出按钮一直显示的状态。直到 GNOME 50 发布时，这些底层错误被修复，2012 年最初的设计意图才终于成为用户实际体验到的默认行为。

所以，如果你是在 GNOME 50 或更高版本中突然发现登出按键不见了，这并非一个仓促的移除决定，而是一个延迟了 14 年才落地的古老设计。

为什么会取消？

取消单用户系统登出按键的原因，是基于一个界面简化的设计理念。

核心逻辑是：如果系统上只有一个用户账户，那么“登出”和“关机/重启”在场景上似乎有所重叠——用户要么继续使用，要么就可以直接关闭计算机，单独“登出到登录界面”的步骤可能被视为多余。因此，设计团队决定在这种情况下隐藏登出选项，让菜单更简洁。

然而，这个设计在实际推出后引发了大量讨论和批评。反对意见认为，登出是一个基本且普遍的用户操作，不应被隐藏。例如，在 Wayland 会话下，某些操作（如重新加载 GNOME Shell 扩展）可能需要登出再登录才能生效。更有观点指出，在主流桌面操作系统中，GNOME 50 的这种行为是独一无二的，对用户来说并不直观。

小结

GNOME 登出按键消失并非永久取消，而是单用户系统隐藏登出选项的设计在 GNOME 50 中真正生效。若需要恢复，执行：

现代化ls替代工具eza简介与配置

发表于 2026-10-30

在日常的终端操作中，ls 是我们使用频率最高的命令之一。如果你想让枯燥的黑白文件列表变得更加美观、直观且信息丰富，那么是时候了解一下现代化的 ls 替代工具——eza 了。

eza 简介

eza 是一个用 Rust 语言编写的现代 ls 命令替代品（它是已停止维护的 exa 项目的活跃分支）。它不仅运行极快，还带来了许多令人惊艳的特性：

  • 超强视觉表现：默认使用丰富的颜色来区分文件类型，并原生支持在文件名旁显示精美的小图标。
  • 内置 Git 状态：使用 --git 参数，可以直接在文件列表中查看文件的 Git 状态（如未跟踪 ??、已修改 M 等），对开发者极为友好。
  • 树状视图：使用 --tree 参数，可以像 tree 命令一样递归展示目录结构，且速度更快、支持色彩渲染。
  • 人性化细节：支持按大小、时间、扩展名等灵活排序，支持“人类可读”的文件大小显示，以及让目录优先显示等。

注意：如果你系统里仍然只有旧版的 exa，建议尽快安装 eza。目前主流包管理器（如 apt, pacman, brew）均已提供 eza 的安装源。

前置准备：安装 Nerd Font

eza 的图标功能依赖于 Nerd Font（一种包含大量图标和特殊符号的修改版字体）。如果不配置字体，终端里可能会出现方块或乱码。

  1. 下载并安装字体：前往 Nerd Fonts 官网 下载你喜欢的字体（如 JetBrainsMono Nerd Font 或 FiraCode Nerd Font）。
  2. 配置终端：打开你使用的终端模拟器（如 Windows Terminal, iTerm2, Alacritty 等），在设置中将默认字体修改为你刚刚安装的 Nerd Font。
  3. 版本建议：建议安装 Version 3 及以上的字体版本，以获得最全的图标支持。

推荐配置

将以下别名（Aliases）配置添加到你的 Shell 配置文件中（如 ~/.zshrc 或 ~/.bashrc），即可享受开箱即用的极佳体验：

参数贴士

  • --icons=auto：智能判断当前环境是否支持图标，如果不支持（例如在无字体的远程服务器上），会自动回退到无图标模式，避免乱码。

  • --group-directories-first：将文件夹排在文件前面，让目录结构更加清晰。

  • --human-readable：将文件大小显示为 1K, 23M 等更易读的格式，而不是字节数。

今天决定把我的 Thinkpad T490 的双系统改为单一的 Windows10LTSC2021, 原因是我的台式机已经配置了 ArchLinux + Windows11 双系统，平时的办公主力为 ArchLinux , 如果笔记本使用 Windows10LTSC2021, 则在 Windows 下的工作直接使用笔记本办公即可。但是，在安装完成 Windows10LTSC2021 后发现输入法的候选框不显示，这是 Windows10LTSC2021 的一个已知的 Bug, 其根本原因在于，微软在精简这个版本时，不小心删除了新版自由软件拼音输入法所依赖的 桌面桥运动时(Desktop Bridge Runtime) 组件。因为缺少必要的运行库，所以输入法就无法正常显示候选框。

方案一：切换到旧版输入法

这是最快捷的临时解决方案，能让输入法立刻恢复正常，操作步骤为：

  • 在任务栏右下角右键点击“中/英”输入法图标，选择设置
  • 在设置窗口中点击常规
  • 找到兼容性部分，打开使用以前版本的微软拼音输入法开关。

方案二：安装缺失的依赖库（更彻底）

这是从根源上解决问题的方法，并且已经被广泛验证有效。其步骤为：

  1. 下载文件：依赖库文件Microsoft.VCLibs https://dl.lancdn.com/landian/soft/vclibs
  2. 解压文件：将下载的压缩包解压，你会得到两个.Appx格式的文件。
  3. 放置文件：将这两个.Appx文件复制到C:盘的目录下。
  4. 安装文件：
    • 右键点击开始菜单，选择Windows PowerShell(管理员)或终端(管理员)
    • 在打开的窗口中，根据你的系统类型，输入以下命令并回车
      • 64位系统
      • 32位系统
  5. 重启电脑：命令执行成功后，重启电脑即可生效。

[!WARNING] 如果提示“部署失败”或“资源正在使用中”，可以重启电脑后再试一次。
